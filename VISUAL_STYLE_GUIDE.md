# Visual style guide — WVA Donor Retention Analytics

**Direction:** minimal editorial analytics: generous whitespace, concise findings, calm highlights and direct value labels.

| Role | Colour |
|---|---|
| Heading / reference | Deep navy `#253B53` |
| Main comparison / evidence | Muted teal `#168E8B` |
| Secondary groups | Slate blue `#8197B2` |
| Meaningful contrast | Soft coral `#E58C78` |
| Supporting warmth | Champagne `#D8AB66` |
| Background | Warm off-white `#FAFAF8` |

Visual grammar: use the same colour for the same semantic role; use dots for close metrics, dumbbells for paired groups, rounded horizontal marks for magnitude, light arrows for proposed flows. Zero is visible on ratio/rate bars; the model ROC-AUC dot plot explicitly notes its zoomed scale. Percentages refer to distinct cohorts where noted.

**Sources:** Part D final report and saved notebook aggregates; source data was not independently rerun. No plots imply causal effects or implemented campaigns. Permission to publicly disclose client-derived figures remains to be confirmed.

**Positioning:** README one flagship Top-K; Stage 3 eight descriptive figures; Stage 4 four evaluation figures; Stage 5 three business-framework diagrams.
