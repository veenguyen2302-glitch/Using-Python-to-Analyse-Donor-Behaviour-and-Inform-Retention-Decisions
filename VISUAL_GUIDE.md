# Visual guide — World Vision Australia Donor Retention Analytics

All charts are redrawn from historical aggregated values in Part D. No client-level data is embedded. No financial or pilot results have been invented. The main pages use repository-root-relative paths under `assets/`.

## Visual hierarchy

- **README**: one anchor visual, `top20-prioritisation.png`.
- **Stage 3**: overview → cohort → amount → product → channel → within-product → relationship → timing.
- **Stage 4**: temporal cohort → model comparison → permutation importance → Top-20% result.
- **Stage 5**: evidence-to-action recommendations → business-value framework → secondary proposed pilot.

## Accuracy and boundaries

- Stage 3 descriptive sample: 19,194 eligible supporters; Stage 4 Mass final test: 6,741. Do not combine baselines.
- Timing chart describes 3,194 eventual repeat supporters, not the whole cohort.
- Child Rescue total sample size omitted where independent confirmation was unavailable.
- ROC-AUC dot plot uses a **labelled zoomed axis**, not a zero-baseline bar chart.
- Model ranking lift is not experimentally established campaign uplift.
- Graphical designs are proposals where labelled; no deployment claimed.
- Public disclosure of WVA-derived aggregate results remains subject to permission.
